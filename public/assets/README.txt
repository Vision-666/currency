Globe asset provenance

world-countries.json contains Natural Earth 1:110m country boundaries.
Natural Earth data is public domain:
https://www.naturalearthdata.com/about/terms-of-use/

The file is served locally and used only to draw country boundaries on the
interactive canvas globe. The globe shading, grid, and atmosphere are
authored in public/app.js; no third-party image or map runtime is loaded.
